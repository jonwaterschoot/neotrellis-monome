# Firmware downloads

UF2 files are published as [GitHub releases](https://github.com/jonwaterschoot/neotrellis-monome/releases), not kept in this folder.

- [Latest release](https://github.com/jonwaterschoot/neotrellis-monome/releases/latest): Pico and dink-ii builds for 16x8, 8x8 and 4x4 grids, plus `selector.lua`. Only the Pico 16x8 build is tested on hardware.
- [v2026.04, earlier builds](https://github.com/jonwaterschoot/neotrellis-monome/releases/tag/v2026.04): my first color build (20260419) and okyeron's original iii build (20260327), which used to be in this folder.

To build them yourself, see `tools/build-variants.sh` and the [firmware README](../README.md#building-other-boards-and-grid-sizes).
